A dozen AIs, a dozen islands

Decide something in ChatGPT and Codex never hears about it. Change your mind in Claude and Cursor keeps building the old plan. Every tool has its own memory, and none of them talk.

Chat apps

ChatGPT memory, Claude Projects, Gemini Gems, Grok and Perplexity threads: each a private memory in someone's cloud, with no way to write back to your repo.

Coding agents

Claude Code, Codex, Cursor, Copilot, Gemini CLI, Windsurf, aider: each keeps its own transcripts on this machine only, and none knows what the others did yesterday.

Your repo

The code changes, but the why lives in a chat nobody else can see. When a decision changes, agents keep working on the stale one.

Sources and the full survey of every tool's hooks, logs and connectors: RESEARCH.md

      Connect any AI
      
  
      hamyad init --all wires every coding tool in your repo. hamyad connect <tool> prints the exact steps for the rest. Anything else can use MCP, the REST/OpenAPI endpoint, or the always-fresh MEMORY.md.
      
  
      
  
      
    
      
      
      Chat apps need a public URL
      
      
      They call connectors from their own cloud. Use the free Cloudflare Worker over your GitHub repo, or with no GitHub at all run hamyad serve --token … next to your shared folder and expose it with cloudflared tunnel.
      
    
      
    
      
      
      No GitHub? One file is enough
      
      
      hamyad init --all --store ~/Dropbox/shop/MEMORY.md keeps the whole brain in one Markdown file in Dropbox, Google Drive or a cowork folder. Upload that same file to any chat that only takes files.

      Set it up in ten minutes
      
  
      
    
    
    
  
      
  
      
    
      Inside your repo. init --all creates .brain/ and merges MCP servers, hooks and rules for Claude Code, Codex, Gemini CLI, Cursor, Copilot, Windsurf, Zed, Roo, Junie and aider, without touching anything already there.
      

      cd my-project
curl -fsSL https://mrzroot.github.io/hamyad/install.sh | sh      # Windows: irm https://mrzroot.github.io/hamyad/install.ps1 | iex
#  = install Node if missing + hamyad + `hamyad setup` (init --all, pre-approve tools)
# already have Node 20+?  npm i -g https://github.com/mrzroot/hamyad/releases/latest/download/hamyad.tgz && hamyad init --all
git add -A && git commit -m "Add hamyad brain" && git push
hamyad import      # past chats from Claude Code, Codex, Gemini, Copilot, Cursor, Windsurf, aider
hamyad status      # which tools are wired, last session of each

      Things hamyad will never do
      
  
        
    
      • Store your API keys. Secrets are redacted from chats, prompts and diffs before anything is written.
        • 
    
      • Push your work in progress. It pushes only when every unpushed commit is a brain: commit.
        • 
    
      • Capture full transcripts unless you opt in. The default is a short summary.
        • 
    
      • Run a public server without a token. Workers and hamyad serve refuse to.
        • 
    
      • Lock you in. It is a folder of Markdown. Delete hamyad and the notes stay.

      Questions
      
  
      Does it need an OpenAI or Anthropic API key?
      No. The thinking happens in whichever AI you already use; hamyad only stores, summarises (without any model call) and serves.
      
  
      Which tools are really tested?
      Claude Code, Codex, Gemini CLI, Copilot CLI and aider run for real against a mock model server in our e2e suite: hooks fire, sessions and diffs are captured, and “decisions changed” reaches each model. Cursor, Windsurf, Zed, Roo and JetBrains configs are verified by parsing; chat-app connectors need your account.
      
  
      I am in Iran. Will the connectors work?
      Yes. ChatGPT, Claude.ai and Grok connect to your Worker from their servers, not from your device, so domestic filtering of workers.dev does not affect them. You may need open internet once to deploy.
      
  
      What about teams?
      Everyone with repo (or folder) access shares the brain. The remote endpoint uses one token per deployment; OAuth per person is on the roadmap.
      
  
      Can I edit entries by hand?
      Yes, in your editor, on github.com, or right inside MEMORY.md.
