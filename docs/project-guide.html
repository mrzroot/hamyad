PROJECT WALKTHROUGH

Pilot a shared project brain before giving it real history or remote access.

  1. Start in a disposable checkout

    Begin with capture off so you can inspect configuration and generated files before opting into any session capture.

    hamyad init --all --capture off
hamyad status

  2. Share an intentional note

    Add one synthetic project decision, then inspect a Markdown export before sharing. Do not test with production transcripts, credentials or personal data.

    hamyad add decision 'Use a local test database'
hamyad export --out preview-memory.md

  3. Treat remote access separately

    This project's remote endpoint uses a shared token, not per-user OAuth. Do not expose the test store publicly; decide who can read or write before enabling remote access.

راهنمای عملی پروژه

پیش از اتصال تاریخچهٔ واقعی یا دسترسی از راه دور، حافظهٔ مشترک را آزمایش کنید.

  1. شروع در محیط آزمایشی

    ابتدا ثبت نشست‌ها را خاموش نگه دارید تا بتوانید تنظیمات و فایل‌های تولیدشده را بررسی کنید.

    hamyad init --all --capture off
hamyad status

  2. یادداشت ساختگی را امتحان کنید

    یک تصمیم ساختگی وارد کنید و فایل خروجی را پیش از اشتراک بررسی کنید؛ از دادهٔ واقعی استفاده نکنید.

    hamyad add decision 'Use a local test database'
hamyad export --out preview-memory.md

  3. دسترسی از راه دور را جداگانه بررسی کنید

    اتصال راه دور از توکن مشترک استفاده می‌کند. قبل از فعال‌سازی، دسترسی خواندن و نوشتن را مشخص کنید.
